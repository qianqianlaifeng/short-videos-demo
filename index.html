      02 / COVERAGE
      
支持平台

      
聚合入口自动识别来源平台；亦可手动指定单平台端点以缩短链路。抖音支持原画 302 解析，视频 / 图集 / 实况三类内容统一契约输出。

    

    

    

      关于可用性的说明：各平台解析能力依赖上游接口，平台方策略调整可能导致个别通道临时失效；抖音主页批量解析需要登录 Cookie，属独立接口。此页为技术演示，不保证任何平台的长期可用性。

      05 / DEPLOYMENT
      
部署与后端说明

      
GitHub Pages 仅托管静态资源，本页所有解析请求均在浏览器端直连公共接口。若需私有化后端，可在自有 PHP 主机或 Cloudflare Workers 上部署同一仓库。

    

    

      

        
 后端部署路径

        

          
PHP 主机：将 short_videos 仓库上传至站点根目录，PHP 8.0+ 并启用 curl / json 扩展，无需 Composer。访问 /api/sv.php?url=… 即可。

          
Cloudflare Workers：部署 api/douyin-cloudflare workers/workers.js（抖音整合版），可获得边缘网络与更稳定的 CORS 行为。

          
403 代理：部署 cf_sv_proxy/worker.js，用于转发带防盗链的视频直链。

          
切换前端端点：修改 assets/data.js 中 API_CONFIG.primary 与 API_CONFIG.platforms，重新提交即生效。

        

      

      

        
 GitHub Pages 部署

        

          
仓库根目录放置 index.html、assets/ 与 .nojekyll；.nojekyll 用于避免 Jekyll 忽略下划线目录。

          
在仓库 Settings → Pages 中选择 Deploy from a branch → main / root，或使用仓库内置的 .github/workflows/pages.yml 工作流。

          
项目页访问路径为 https://<用户名>.github.io/<仓库名>/；若仓库命名为 <用户名>.github.io，则直接位于根域名。

          
全站相对路径引用，无构建步骤、无外部 CDN 依赖，可同时部署到任意静态托管服务。
