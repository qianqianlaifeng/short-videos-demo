 音乐接口规范

    

      

        
MUSIC REQ 通道与请求参数

        

          

            
通道端点主要参数

            
              
网易云音乐/api/163_musictype=json + url / ids + level；歌名用 type=search&s=

              
QQ 音乐/api/qqmusicurl + type=song；name + type=search

              
酷我音乐/api/kuwourl · 播放页链接

              
汽水音乐/api/qsmusicurl · 分享短链

              
音乐聚合/api/musicid + media=tencent/netease + type=song

            
          

        

        

          
输入自适应：粘贴歌曲链接时原样传递；纯数字按歌曲 ID 处理；其余文本按歌名搜索。歌名搜索返回候选列表，点击任一结果会二次请求直链。

          
音质：网易云通道可选 standard / exhigh / lossless / hires / jyeffect / sky / jymaster，高音质能否返回取决于上游账号权限。

          
跨域：五个音乐端点均返回 Access-Control-Allow-Origin: *，静态页可直接调用。

        

      


      

        
MUSIC RES 前端归一化字段

        
五个通道的响应结构差异较大（裸 JSON / code+msg+data / code+message+data:null / 歌曲列表），前端统一为下列字段后再渲染播放器、歌词与歌曲信息。

        

          

            
字段类型说明

            
          

        

        
CODE 音乐常见状态

        

          
200解析成功（网易云裸响应用 status:200）

          
1003酷我：付费内容或歌曲已下线

          
400缺少必填参数（如 163 的 type）

          
error上游返回非 JSON，页面保留原始响应文本

        

      

    

  







  

    

      05 / DEPLOYMENT
      
部署与后端说明

      
GitHub Pages 仅托管静态资源，本页所有视频与音乐解析请求均在浏览器端直连公共接口。若需私有化后端，可在自有 PHP 主机或 Cloudflare Workers 上部署同一仓库。

    

    

      

        
 后端部署路径

        

          
PHP 主机：将 short_videos 仓库上传至站点根目录，PHP 8.0+ 并启用 curl / json 扩展，无需 Composer。访问 /api/sv.php?url=… 即可。

          
Cloudflare Workers：部署 api/douyin-cloudflare workers/workers.js（抖音整合版），可获得边缘网络与更稳定的 CORS 行为。

          
403 代理：部署 cf_sv_proxy/worker.js，用于转发带防盗链的视频直链。

          
切换前端端点：修改 assets/data.js 中 API_CONFIG.primary、API_CONFIG.platforms 与 API_CONFIG.music，重新提交即生效；音乐请求参数在 app.js 的 buildMusicRequest() 中适配。

        

      

      

        
 GitHub Pages 部署

        

          
仓库根目录放置 index.html、assets/ 与 .nojekyll；.nojekyll 用于避免 Jekyll 忽略下划线目录。

          
在仓库 Settings → Pages 中选择 Deploy from a branch → main / root，或使用仓库内置的 .github/workflows/pages.yml 工作流。

          
项目页访问路径为 https://<用户名>.github.io/<仓库名>/；若仓库命名为 <用户名>.github.io，则直接位于根域名。

          
全站相对路径引用，无构建步骤、无外部 CDN 依赖，可同时部署到任意静态托管服务。
